# TP Vision por Computadora III — Defensible Space

Trabajo Práctico Final de Vision por Computadora III (CEIA · FIUBA).

Detección automática de incumplimiento del protocolo municipal de defensible space en Villa La Angostura (Neuquén), sobre ortofotos de dron.

Marco: proyecto Lawal aprobado por HOT Open Call 2026 ("Map your city with fAIr").

## Setup

Requiere [uv](https://github.com/astral-sh/uv) (manejador de paquetes Python).

```bash
uv sync
```

Instala el ambiente en `.venv/` con las dependencias declaradas en `pyproject.toml`.

## Documentación

`docs/` contiene los documentos del proyecto:

- `PROPUESTA_TP.html` — planteo del problema, pipeline de modelos, propuesta de mejora
- `DATA_PIPELINE.html` — pipeline operativo de datos
